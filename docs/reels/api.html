Platform API (for apps and AI tools)

The platform exposes a REST API (Supabase PostgREST). Base URL: https://eyasbfywyatrkpkljxek.supabase.co/rest/v1

Header: apikey: <publishable key> (the public key used by the website). To act as a user, also send Authorization: Bearer <that user's access token>. Every request is limited by row-level security: a tool can only do what that signed-in user can do.

Public reads (no login)

GET /channel_stats channels with follower and reel counts
GET /posts?order=created_at.desc&limit=20 posts
GET /series series and films
GET /lives?status=eq.live live streams now

As a signed-in user

POST /posts, POST /follows, POST /reports, POST /lives, POST /series (own channel only). Media upload goes to Storage bucket media, only inside the user's own folder, max 50 MB, image/video types.

Rules
  • Never use or share a service-role key. It is not part of any client or tool.
  • Rate limits per user: 30 posts/hour, 10 series/day, 10 lives/day, 5 groups/day, 20 reports/day.
  • Private data (profiles, earnings, group lists, memberships) is not readable through the public key.
  • Scraping or bulk analysis of platform data, or content that is not yours, is against the terms.
  • AI features that need secret keys (captions, assistant) will run server-side only (Edge Functions), never in the browser.
